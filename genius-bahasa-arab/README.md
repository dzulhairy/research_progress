# Jom Arab

Permainan pembelajaran Bahasa Arab untuk kanak-kanak: 7 bahagian, 105 tahap dan kemajuan pada peranti.

Main: https://dzulhairy.github.io/research_progress/genius-bahasa-arab/

Salinan statik ini boleh diterbitkan terus melalui GitHub Pages daripada branch main, akar repositori. Semua aset menggunakan laluan relatif; tiada pemasangan pakej atau API key diperlukan. Semakan tulisan dibuat oleh ibu bapa. Suara Arab menggunakan suara yang tersedia pada peranti.
